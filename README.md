# Wolfpack.fm

Underground music platform frontend -- playlists, artists, interviews and
features, reviews, guest posts, and underground rap discovery.

This is the **frontend only**. It's built with React, Vite, and React
Router, and is part of a larger PERN (PostgreSQL, Express, React, Node)
architecture -- the backend/API/database lives in a separate repository
that will connect to this frontend later.

## Stack

- React
- Vite
- React Router
- Plain CSS (no CSS framework)
- Lucide React (icons)

## Getting started

```bash
npm install
npm run dev
```
